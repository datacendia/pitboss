Compose the segment, not the screenshot

Read the brief, build the definition, get it marked. Ten exercises covering the errors that actually cost people: session scope where user scope was needed, co-occurrence mistaken for sequence, a missing negative, a missing property filter.

Conditions

What these drills are checking

Scope

Session scope asks "which visits had this shape". User scope asks "which people ever did this". Anything containing the words never, has ever or across sessions is user scope, and getting it wrong does not produce an error — it produces a plausible number that answers a different question.

Sequence

The single most common segment-building error. A and B is not A then B. Without ordering, "failed then retried" also matches a player who succeeded and later deposited again. Whenever a brief contains the word "then", reach for the sequence operator.

Negatives

Nearly every valuable gambling segment is a negative: deposited but never wagered, registered but never verified, searched but never launched. On a dual-product operator you usually need two negatives, or you quietly include every sports bettor in your "did not play" population.

Property filters

The filter is often where the entire meaning lives. Lobby Search is every search; Lobby Search where hadZeroResults = true is the finding. A KYC Outcome of "referred" is not a pass, and an in-play bet is not a pre-match one.
